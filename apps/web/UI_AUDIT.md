### Подсказки и выбор составляющих мощности

Селектор составляющей удалён: разложение, Sankey и процентная структура позволяют выбрать элемент непосредственно на графике, включая keyboard activation. Для потери отображаются конкретные применимые мероприятия с расчётным годовым денежным эффектом; неизвестный CAPEX остаётся обозначенным. Общее сообщение про «связь составляющей с мероприятием» удалено. Полезная мощность не получает фиктивных мероприятий.

Tooltip показывает название один раз, величину с единицей и исходную долю, если она сохранена. Waterfall выводит исходную мощность составляющей, сохраняя знак коррекции и не меняя знак шага диаграммы. Доли не перенормируются. В графиках времени сохраняются timestamp и имена рядов. Native SVG tooltips не дублируют HTML подсказку.

Клик мышью не рисует рамку SVG или элемента; клавиатурное выделение чёрное, задано отдельным `--chart-focus`. Modality переключается по pointer/keyboard событиям; изменение масштаба и выбор snapshot сохранены. Убрана зелёная рамка подсвеченной формулы.

Executed: unit tests модели tooltip, browser checks исходных 309,67 кВт / 45,05% во всех трёх режимах, отсутствия селектора, предложенных мероприятий и pointer/Tab focus. Расчётное ядро не менялось; сервер не обновлялся.

Итог уточнения: build, 46 unit tests, полный проход 63 E2E и дополнительный сценарий одиночного столбчатого ряда прошли. Отдельно повторены проверки pointer/Tab focus и компактного tooltip. Тултип одного значения выровнен одной колонкой. Локальные проверки не означают проверку всех реальных объектов; коммиты и deployment этого изменения не выполнялись.

### Отзывчивость общего курсора

- Группы сигналов, массивы для Plot и layout сохраняют identity до изменения данных
  или маркера измерения. Движение курсора не запускает повторную нормализацию моделей.
- Таблица исходных измерений и её колонки не строятся заново на каждом pointer event.
  Intl-форматтеры чисел кэшируются по точности; форматтеры подписей осей переиспользуются.
- Executed: replay 90 pointer events на реальной месячной телеметрии в Chromium/dev,
  с одинаковым CPU-profiler: median 114,4 → 16,7 ms, p95 468,8 → 28,2 ms.
  Это локальный dev-замер, не production benchmark. Regression test проверяет, что
  движение курсора не вызывает новых buildChartModel/Intl.NumberFormat и что общий
  курсор продолжает отображаться на всех графиках. Исходные точки не прореживаются.
