# Словарь объектов и терминов

Этот файл хранит только подтверждённые значения и псевдонимы. Для расчётов
канонический идентификатор берётся из `config/plants/`, а происхождение сигналов —
из `config/telemetry_sources.yaml`.

| Термин | Значение |
| --- | --- |
| КНС | Кустовая насосная станция. |
| ДНС | Дожимная насосная станция. |
| НА | Насосный агрегат. Номер агрегата сохраняется как в источнике: `НА-02` и `НА-2` — один агрегат после нормализации источника. |
| БГ | Блок гребёнки; давление БГ — давление в напорном коллекторе перед водоводами. |
| АН | НГДУ «Альметнефть» |
| БН | НГДУ «Бавлынефть» |
| ДжН | НГДУ «Джалильнефть» |
| ЕН | НГДУ «Елховнефть» |
| ЛН | НГДУ «Лениногорскнефть» |
| ОПУ | Первичные отчёты не расшифровывают аббревиатуру. Использовать только как часть канонического имени «КНС-ОПУ», не выводить расшифровку. |
