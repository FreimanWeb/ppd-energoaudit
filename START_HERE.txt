КАК ЗАПУСТИТЬ ПРОЕКТ «ЭНЕРГОАУДИТ ППД»

Windows — одной кнопкой
1. Распакуйте архив в папку без длинного пути, например C:\ppd-energoaudit.
2. Дважды щёлкните START.cmd.
   При первом запуске скрипт сам установит uv (менеджер Python) и, если есть
   winget, Node.js; затем пакеты и база данных — 3–5 минут. Дальше запуск
   занимает несколько секунд.
3. Браузер откроется сам: http://127.0.0.1:5173
   Выберите КНС-54, агрегат НА-1, дату 24.10.2026.
4. Остановить — закрыть окно START.cmd (или Ctrl+C в нём).
   Если осталось свёрнутое окно uvicorn — закройте и его.

Автотесты: дважды щёлкните TESTS.cmd (1–2 минуты, в конце «Все проверки пройдены»).

Linux, macOS или Git Bash:  ./run.sh   (тесты: ./run.sh test)

Что посмотреть
- Обзор → Карта потерь: щелчок по столбцу открывает подробности статьи.
- Машинный блок → Рекомендации: адресная диагностика, бенчмарки, дефекты 1С ТОИР.
- Данные и методика → Справочник: шероховатость, правила диагностики, бенчмарки, алгоритм НА.
- Трубопроводы → Разводящая сеть.

Если не запускается
- «Node.js не найден» — установите LTS с https://nodejs.org и запустите снова.
- «порт занят» — закройте другие копии приложения или перезагрузите компьютер.
- Нет данных на графиках — удалите файл telemetry.sqlite и запустите START.cmd снова.
